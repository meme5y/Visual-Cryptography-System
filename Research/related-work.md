# Related Work in Visual Cryptography

## Academic Research

### Foundational Papers
1. **Naor & Shamir (1994)**: "Visual Cryptography"
   - Introduced concept of sharing secret images
   - Basis for many subsequent visual crypto systems

2. **Kahn (1967)**: "The Codebreakers"
   - Historical context for visual communication
   - Pre-computer era crypto techniques

3. **Wang et al. (2017)**: "LED-to-Camera Communication"
   - Modern applications of light-based communication
   - High-speed data transmission techniques

## Open Source Projects

### 1. Li-Fi Projects
- **OpenVLC**: Open-source Visible Light Communication
  - University-based research platform
  - Supports up to 1 kbps data rate
  - GitHub: https://github.com/openvlc

- **LuxPython**: Python library for light communication
  - Simple API for LED/camera systems
  - Educational focus

### 2. Arduino-Based Systems
- **Arduino-LiFi**: Basic Li-Fi implementation
  - Similar to our project but more complex
  - Uses photodiodes instead of cameras

- **Visual-Morse**: Morse code with RGB LED
  - Simpler approach, no encryption
  - Good for beginners

### 3. Educational Tools
- **CryptoLED**: MIT educational project
  - Focuses on teaching XOR encryption
  - Similar concept but less feature-rich

- **LightCipher**: University of Cambridge project
  - More advanced cryptographic techniques
  - Professional-grade implementation

## Commercial Products

### 1. Li-Fi Systems
- **pureLiFi**: Commercial Li-Fi products
  - Gigabit-speed light communication
  - Enterprise-grade security

- **Signify (Philips)**: Li-Fi enabled lighting
  - Integration with existing infrastructure
  - Professional installation required

### 2. Educational Kits
- **Arduino Starter Kit**: Includes light communication projects
- **Raspberry Pi Sense HAT**: Can be adapted for visual crypto
- **Makeblock mBot**: Robotics platform with light sensors

## Comparison with Our Project

### Unique Features of SecureLight:
1. **Multi-speed operation**: Adaptive to learning pace
2. **Auditory feedback**: Enhanced learning experience
3. **Physical interface**: Button controls alongside serial
4. **Comprehensive documentation**: Educational focus

### Advantages:
- **Lower cost**: ~$20 vs. $200+ for commercial kits
- **Open source**: Full access to code and design
- **Educational focus**: Designed for learning
- **Modular design**: Easy to extend and modify

### Limitations Compared to Advanced Systems:
- **Lower bandwidth**: 10 bps vs. Mbps in commercial Li-Fi
- **Simpler crypto**: XOR vs. AES in secure systems
- **Manual alignment**: No auto-tracking like professional systems
