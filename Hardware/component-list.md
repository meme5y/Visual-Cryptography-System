# Component List

## Required Components:

| Component | Quantity | Specification | Notes |
|-----------|----------|---------------|-------|
| Arduino Uno | 1 | ATmega328P | Or compatible (Uno R3) |
| RGB LED | 1 | Common Cathode | 5mm, 4-pin |
| Resistors | 3 | 220Ω, 1/4W | For LED current limiting |
| Push Buttons | 2 | Tactile, 6mm | Momentary switch |
| Piezo Buzzer | 1 | Passive | 5V operation |
| Breadboard | 1 | 400/800 points | For prototyping |
| Jumper Wires | 10-15 | Male-to-male | Various colors |

## Optional/Alternative Components:

| Component | Alternative | Notes |
|-----------|-------------|-------|
| Arduino Uno | Any Arduino with 3+ PWM pins | Leonardo, Micro, etc. |
| RGB LED | 3 separate LEDs (R, G, B) | Use 3 discrete LEDs |
| Buttons | Any NO push button | Size/shape can vary |
| Buzzer | Active buzzer (3V) | Adjust code for active high |

## Estimated Cost:
- **Low-end**: $15-20 (with Arduino clone)
- **Mid-range**: $25-30 (with genuine Arduino)
- **Educational kits**: Usually include all components

## Tools Required:
- Computer with Arduino IDE
- USB A-B cable
- Wire cutters/strippers
- Multimeter (optional, for testing)
